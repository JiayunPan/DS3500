# Required Functions

## 1. `setup_logging(verbose=False)`

Configure Python's logging system.

Your function must:

* Use `logging.DEBUG` when `verbose` is `True`.
* Use `logging.INFO` when `verbose` is `False`.
* Include the **time, log level, and message** in each log entry.

For example:

```text
10:23:01 DEBUG    Arguments parsed: input=data/sales.csv, output=results/clean.csv
10:23:01 INFO     Input file validated: data/sales.csv
```

---

## 2. `parse_arguments()`

Use `argparse` to define the following command-line arguments:

| Argument          | Required? | Description                                      |
| ----------------- | --------- | ------------------------------------------------ |
| `--input`, `-i`   | Yes       | Path to the input file                           |
| `--output`, `-o`  | Yes       | Path to the output file                          |
| `--format`        | No        | Output format: `csv` or `json`; default is `csv` |
| `--verbose`, `-v` | No        | Enable verbose logging                           |

Requirements:

* `--input` and `--output` must be required.
* `--format` must accept only `csv` or `json`.
* The default output format must be `csv`.
* `--verbose` / `-v` should enable verbose logging.
* The function should return the parsed arguments.

---

## 3. `validate_input(filepath)`

Check whether the input path exists **and is a file**.

Use `pathlib`:

```python
Path(filepath).is_file()
```

Your function must:

* Return `True` if the input path is a valid file.
* Log an `ERROR` message and return `False` if the path is not a valid file.
* Log an `INFO` message when the input file is successfully validated.

For example:

```text
10:23:01 INFO     Input file validated: data/sales.csv
```

If the file is missing:

```text
10:23:15 ERROR    Input file not found: fake.csv
```

---

## 4. `main()`

Use the functions above to organize the program workflow.

Your `main()` function should:

1. Parse the command-line arguments.
2. Set up logging using the `--verbose` option.
3. Log the parsed arguments at the `DEBUG` level.
4. Validate the input file.
5. Exit with status code `1` if the input file is invalid.
